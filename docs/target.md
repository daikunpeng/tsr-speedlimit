# 项目目标

## 中级目标

实现 **YOLOv5 级检测器 + 小分类模型** 的中国场景限速标志检测与识别。

## 最终部署

| 项 | 要求 |
|----|------|
| 平台 | 地瓜派 **RDK X5** |
| 相机 | GS130WI（约 120° 宽角，畸变大） |
| 输入 | 已去畸变图像，**640×352** |
| 在线帧率 | ≥ **10 Hz** |
| 离线目标 | 尽量 ≥ **60 Hz** |

策略细节、两级架构、数据优先顺序见 [`strategy.md`](strategy.md)。
