# Classifier v3 级联评估（牌面颜色/曝光增广）

## 结论先行

- cls v3 = v2 同数据/同架构/同训练参数，唯一新增**训练期牌面颜色/曝光增强**
  （概率 0.5：暗红/发白/亮度-饱和-伽马抖动，hue 不动；test 不增强）。
- 把 self GT-crop 分类从 **112/185（60.5%）→ 159/185（85.9%）**；
  暗红 `_7` pl40 8/20→19/20、`_5` pl20 15/24→23/24、`other` 误杀 51→14。
- **级联（det conf=0.5）**：

| 组合 | TT100K E2E | self E2E | self cls acc(detTP) | self 24–32px E2E | self 事件@0.5 |
|------|-----------:|---------:|--------------------:|-----------------:|--------------:|
| smoke1 + v2 | 84.2% | 9.7% | 81.8% (18/22) | 40.0% | 2/3 |
| smoke1 + v3 | **84.4%** | 10.8% | 90.9% (20/22) | 36.7% | 3/3 |
| tt_crop1 + v2 | 80.6% | 9.2% | 56.7% (17/30) | 40.0% | 2/3 |
| **tt_crop1 + v3** | 80.4% | **15.1%** | **93.3% (28/30)** | **53.3%** | **3/3** |

- self E2E 从 9.7% 提升到 **15.1%**（相对 +55%），三个可验事件全部通过
  （`_5` pl20 5/5、`_7` pl40 4/5、`_3` pl40 5/5）；`_5` 在 v2 下始终 2/5。
- v3 不损害 TT100K：smoke1+v3 84.4% ≥ smoke1+v2 84.2%；
  tt_crop1 的 TT100K 回撤（84.2→80.4）来自其宽画幅裁切训练（丢弃窗口外内容），
  非 v3 引入。TT100K 目标带 12–28px E2E：smoke1+v3 93.6%、crop1+v3 90.6%。

## 细节

- 分类器 crop 级：v3 speed acc 95.69%（v2 96.43%）、label 负拒绝 98.9%（v2 98.7%）、
  detfp 拒绝 58.1%（v2 61.9%）、speed 误杀 other 106（v2 58）。
  clean-crop 上小幅回退，但 self 域边界样本大幅改善，级联净收益为正。
- self E2E conf0.25 与 conf0.5 事件均为 3/3；conf0.25 的速度 FP 增至 17（1 条
  <7px 候选轨迹），故仍以 **conf0.5** 为工作点（6 个速度 FP，0 稳定候选）。
- 未解决：self 仍有 55/185 GT 连 IoU≥0.5 定位都没有（`_9` 34、`_4` 23，
  暗/过曝小牌）；事件覆盖仍 3/10。这是**检测器侧颜色/曝光**的剩余空间。

TT100K 84.2→80.4 为宽画幅训练的既定代价）。是否正式替换默认权重请用户确认。
